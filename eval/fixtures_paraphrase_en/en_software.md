# Product Overview — Kestrel Sync

## Positioning
Kestrel Sync is a document synchronisation and collaboration tool built for teams, and it supports private deployment.

## Version Information
The current release is version 3.2, published on 2026-04-22.

## Performance Parameters
The maximum size for a single file is 2GB.

## Known Issues
Large files sync slowly on first download, and offline conflict merging does not yet support spreadsheet files.
